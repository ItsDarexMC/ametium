Frequently Asked Questions

Answers to the most common questions about Ametium.

Ametium is an addon for Meteor Client that adds some of the most advanced modules to Minecraft.

Ametium supports all versions from 1.21.1 through 1.21.11.

Ametium runs on Fabric. You need Fabric API and Meteor Client, both for the same Minecraft version as the Ametium version you use.

  • Install Fabric API and Meteor Client.
  • Join our official Discord server and download Ametium from the #addon channel, according to your Minecraft version.
  • Put everything in your mods folder and start the game.
